Github repositories

You need to specify the URL of the repository, Github user name and a classic token for the secret. This can be created via your Github settings page via: Developer settings, Personal access tokens, Tokens (classic)

PIXLISE client library authentication

The URL specified needs to be the PIXLISE domain you use (eg https://www.pixlise.org) along with the username and password you use to log in to PIXLISE Name can be anything that helps you remember what this is for NOTE: You will be using the generated id when defining jobs!
